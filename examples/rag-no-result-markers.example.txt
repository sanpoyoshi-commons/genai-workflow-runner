# RAG「該当なし」マーカー設定例（GWR_RAG_NO_RESULT_MARKERS_FILE で指定）。
#
# なぜ要るか：源内 RAG は該当が無くても「空」ではなく "該当なし" の文章を 200 で返す
# （GCP lawsy 由来の固定文を onpre も忠実ポート／AWS は LLM 生成文で常に非空）。
# そのため gwr の「空＝該当なし」だけでは該当なし分岐が出せない。委譲先が返す
# "該当なし" 文を運用者がここに登録すると、outputs が一致したとき docs=[] となり、
# フローの branch len($.vars.docs)==0 が発火する。
#
# 使い方：有効化したい行の先頭 # を外す。1 行 1 マーカー。# 始まり・空行は無視。
# gwr 本体には源内固有の文言を持たせない（＝この設定で注入）。
#
# 源内 law-rag（onpre/オリジナル lawsy 共通）の no-result 文は次の 3 種：

# (1) 法令名を特定できない（クエリに法令名が無い／略称が正式名称に解決できない 等）
# クエリから関連する法令を特定できませんでした。より具体的な法令名（例：民法、刑法、労働基準法など）を含めてクエリを再構成してください。

# (2) 法令名は出たが条文を取得できない（システム不調の可能性）
# 申し訳ございませんが、該当する法令が見つかりませんでした。システムの問題が発生している可能性があります。

# (3) 全文化後に該当条文が空
# 該当する条文が見つかりませんでした。
